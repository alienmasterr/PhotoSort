PhotoSort — Swift Package з відкритим кодом, який підключається до фотобібліотеки iPhone і за обраний період створює звичайні альбоми:
• за домінантним кольором (обрані кольори або всі, що знайшлися);
• за вмістом (наприклад, лише коти або лише собаки за останній рік).
Фото не копіюються й не змінюються: альбом лише посилається на ті самі assets.
